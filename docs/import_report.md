## 使用说明

### 方式一：直接执行SQL
```bash
mysql -u username -p database_name < import_data.sql
```

### 方式二：通过API导入
使用 import_data.json 中的数据，调用系统API：
1. POST /api/categories - 创建主类目
2. POST /api/categories/{id}/sub-categories - 创建细分类目
3. POST /api/items - 创建物品

## 注意事项
1. 执行前请备份数据库
2. 确保类别数据先导入，再导入物品
3. 物品编号使用客户原有编号
4. 停用物品状态设为0（禁用）
