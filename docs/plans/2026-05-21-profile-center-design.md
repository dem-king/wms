# 个人中心设计

**日期：** 2026-05-21

**目标：** 为当前登录账号新增独立的个人中心页面，支持从右上角用户下拉进入，展示当前账号基础资料、安全操作、权限摘要，以及基于后端真实数据返回的最近登录时间和最近登录 IP。

## 现状

- 顶部导航栏右上角仅提供用户名称展示、修改密码和退出登录入口，缺少独立的个人资料页。
- 前端 `userStore` 已具备登录用户快照持久化与刷新恢复能力，适合为个人中心提供首屏兜底展示。
- 后端认证模块已在 `auth_login_log` 中记录登录成功/失败日志，包含 `loginIp` 和 `loginTime` 字段。
- 当前后端没有面向“当前登录用户个人资料”的聚合接口，前端无法直接获取最近登录信息。

## 方案

### 页面与入口

- 新增静态隐藏路由 `/profile`，页面位于 `wms-web/src/views/profile/index.vue`。
- 个人中心不进入左侧菜单，仅通过右上角 `UserDropdown` 中的“个人中心”入口访问。
- `Navbar.vue` 负责接收下拉菜单事件并进行路由跳转；原有修改密码、退出登录能力保持不变。

### 页面结构

- `账号概览`：展示头像、真实姓名、用户名、系统名称和当前账号状态。
- `基础资料`：展示用户 ID、用户名、真实姓名、部门 ID、头像地址或默认占位信息。
- `登录信息`：展示最近登录时间、最近登录 IP，并提供无数据兜底态。
- `安全中心`：提供修改密码、退出登录、刷新资料等操作入口。
- `账户摘要`：展示权限数量、角色数量、token 状态等当前登录态摘要。

### 数据来源

- 页面初始化时请求新的 `/auth/profile` 接口，优先使用后端实时返回的数据。
- 在接口返回前，页面可使用 `userStore.userInfo`、`userStore.permissions`、`userStore.roles` 做首屏兜底展示，避免内容闪空。
- 用户展示名称统一采用 `realName || username || '用户'` 的回退策略。

### 后端接口

- 在 `wms-auth` 模块新增“当前登录用户个人中心信息”查询接口，路径为 `/auth/profile`。
- 接口返回内容包括：
  - 当前登录用户基础资料：`userId`、`username`、`realName`、`avatar`、`deptId`
  - 最近一次成功登录信息：`lastLoginTime`、`lastLoginIp`
- 接口只面向当前登录用户，不允许通过参数查询其他账号。
- 服务层通过当前登录用户 ID 查询用户信息，并从 `auth_login_log` 中按 `loginTime` 倒序取最近一次成功登录记录。

### 后端实现约束

- Controller 仅负责鉴权和调用 Service，不包含业务拼装逻辑。
- 返回 VO，不直接暴露 Entity。
- 最近登录信息通过独立 VO/Converter 组装，避免在 Controller 中手写映射。
- 查询接口补齐 `@PreAuthorize("isAuthenticated()")`，确保符合项目安全规则。

### 前端交互

- 用户从右上角下拉点击“个人中心”后跳转到 `/profile`。
- 页面内再次提供“修改密码”和“退出登录”按钮，保证用户无需返回顶部也能完成账号操作。
- 若后端未返回最近登录信息，则显示“暂无记录”而不是空白或错误。

### 测试策略

- 前端先补 API 与页面结构测试，覆盖个人中心路由、下拉入口和个人资料接口调用。
- 后端补 Service/Controller 相关测试或至少增加前端联调用的最小验证路径。
- 完成后执行前端 `npm test`、`npm run build`，并检查修改文件诊断。

## 不做范围

- 不在左侧菜单新增“个人中心”导航项。
- 不在首版实现头像上传、资料编辑、偏好设置迁移或多设备会话管理。
- 不展示无后端字段支持的最近登录地点、浏览器解析信息、设备指纹等扩展信息。
