# 库房可视化工作台设计

**日期：** 2026-05-21

**目标：** 在 `wms-web/src/views/warehouse/visual/**` 范围内，将现有单页库房可视化重构为工作台结构，补充 2D/2.5D 视图切换、存放柜详情弹窗、按区域/柜/库位编码快速定位与高亮，并收敛旧的错误 API 出口；暂不接入最终布局保存接口。

## 现状

- 现有页面全部集中在 `src/views/warehouse/visual/index.vue`，模板、数据加载、Konva 渲染、摘要面板和交互状态耦合在一起。
- 布局构建和选中态已抽出到 `visual-layout.ts`、`visual-state.ts`，并已有基础单测。
- API 查询已直接使用 `area.ts`、`cabinet.ts`、`bin.ts` 的路径变量风格接口。
- `src/api/warehouse/index.ts` 仍保留旧的聚合出口，包含错误的查询参数式查询接口与未接入的 `visual/*` 出口，当前未被业务代码引用。

## 方案

### 组件结构

- 页面容器 `index.vue` 仅负责拼装工作台区域。
- 新增工作台头部组件，承载库房选择、视图切换、快速定位输入和刷新操作。
- 新增画布组件，负责 2D/2.5D 的 Konva 渲染与节点点击事件派发。
- 新增摘要侧栏组件，负责当前选中对象和统计指标展示。
- 新增存放柜详情弹窗组件，展示柜体基础信息、所属区域、网格规格、库位统计与明细预览。

### 数据与状态

- 保留 `visual-layout.ts` 作为纯模型层，并扩展高亮/搜索辅助索引，继续保证可测试性。
- `visual-state.ts` 从“仅选中态”扩展为“选中态 + 快速定位结果 + 视图模式”的纯状态收敛函数。
- 页面层维护异步数据加载、错误态、弹窗开关和输入值；组件之间通过 props/emits 传递。

### 视图与交互

- `2D` 视图保持当前平面布局语义。
- `2.5D` 视图采用轻量投影视图：区域和存放柜增加顶部与侧边投影块，不引入真实 3D 引擎，保证实现成本和测试稳定性。
- 快速定位支持输入区域编码、存放柜编码、库位编码；命中后自动切换选中链路，并在画布中使用高亮描边和强调填充。
- 点击存放柜可选中柜体，并通过独立入口打开详情弹窗；点击库位时同步联动所属柜体。

### API 收敛

- 保留已正确使用的 `area.ts`、`cabinet.ts`、`bin.ts`、`warehouse.ts`。
- 删除未被引用且路径错误的 `src/api/warehouse/index.ts` 聚合出口，避免后续误用。
- 本次不实现布局保存接口，仅保留前端状态与后续联调所需的类型/交互位置。

### 测试策略

- 先补充或改造失败测试，覆盖组件拆分标记、视图切换、高亮定位、详情弹窗、旧 API 出口清理。
- 纯函数逻辑优先通过 `visual-layout.spec.ts`、`visual-state.spec.ts` 断言。
- 页面骨架与拆分关系继续用源码结构测试，避免引入重型组件挂载成本。

## 不做范围

- 不接入布局保存、拖拽落位和最终持久化接口。
- 不新增后端接口。
- 不引入 3D 引擎或复杂动画系统。
