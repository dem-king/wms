#### 公共工具/组件

- 📄 `wms-web/src/utils/export.ts` — 文件下载工具函数

```typescript
// blob 响应下载工具
export function downloadBlob(blob: Blob, filename: string) {
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = filename
  a.click()
  URL.revokeObjectURL(url)
}
```

#### 功能要点

- 在每个报表页面添加「导出Excel」「导出PDF」按钮
- 按钮点击后调用导出API，传入当前查询条件 + reportType
- 响应为 blob，使用 `downloadBlob` 触发浏览器下载
- 导出期间按钮显示 loading 状态
