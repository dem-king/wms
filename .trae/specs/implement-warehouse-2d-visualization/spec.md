# 2D库房图形展示 Spec

## Why
当前库房、区域、存放柜、库位都以独立表格页管理，用户只能通过层层切换和表格筛选理解空间结构，无法直观看到库房布局。P2 的第 18 个功能需要先建立可点击的 2D 图形视图，作为后续 2.5D 视图、详情弹窗、快速定位和布局编辑器的基础。

## What Changes
- 新增基于 Konva 的库房 2D 图形展示页面，支持区域、存放柜、库位三级联动展示。
- 复用现有库房、区域、存放柜、库位接口，按现有排序和行列信息推导 2D 布局，不在本轮引入坐标编辑。
- 增加图形视图与左侧或顶部选择器联动，支持切换库房、区域高亮、存放柜选中、库位点击。
- 为禁用状态、空数据和加载失败提供明确视觉反馈，避免空白画布。
- 保持现有表格 CRUD 页面可用，2D 图形视图作为只读可视化入口接入。

## Impact
- Affected specs: 库房可视化、区域/柜/库位联动浏览、后续 2.5D/定位/编辑基础能力
- Affected code: `wms-web/src/views/warehouse/**`、`wms-web/src/api/warehouse/*.ts`、`wms-web/src/types/warehouse.d.ts`

## ADDED Requirements
### Requirement: 2D库房画布
系统 SHALL 提供一个基于 Konva 的 2D 库房图形视图，用于展示当前库房下的区域、存放柜和库位结构。

#### Scenario: 选择库房后展示2D布局
- **WHEN** 用户进入 2D 库房图形页面并选择一个库房
- **THEN** 系统加载该库房下的区域、存放柜和库位数据
- **AND** 在画布中按层级绘制区域容器、存放柜块和库位网格

#### Scenario: 库房下暂无布局数据
- **WHEN** 当前库房没有区域或存放柜数据
- **THEN** 页面展示明确的空状态提示
- **AND** 不展示空白且无解释的画布

### Requirement: 区域-柜-库位联动
系统 SHALL 支持在 2D 画布中对区域、存放柜和库位进行点击联动浏览。

#### Scenario: 点击区域高亮该区域
- **WHEN** 用户点击某个区域
- **THEN** 该区域在画布中进入高亮状态
- **AND** 该区域下的存放柜以更清晰的层级展示

#### Scenario: 点击存放柜查看库位网格
- **WHEN** 用户点击某个存放柜
- **THEN** 页面高亮当前存放柜
- **AND** 展示该存放柜的库位网格结构
- **AND** 已选区域状态保持同步

#### Scenario: 点击库位查看基础信息
- **WHEN** 用户点击某个库位
- **THEN** 页面展示该库位的基础信息摘要
- **AND** 当前选中的库房、区域、存放柜上下文保持不丢失

### Requirement: 推导式布局渲染
系统 SHALL 在当前缺少显式坐标字段的前提下，根据现有排序和行列数据推导出稳定的 2D 布局。

#### Scenario: 区域按排序展示
- **WHEN** 系统绘制区域
- **THEN** 区域顺序与 `sortOrder` 保持一致
- **AND** 相同库房下的区域展示顺序稳定

#### Scenario: 存放柜与库位按结构展示
- **WHEN** 系统绘制存放柜和库位
- **THEN** 存放柜根据其所属区域聚合显示
- **AND** 库位根据 `row`、`col` 形成稳定网格
- **AND** 不要求本轮提供拖拽改位能力

### Requirement: 状态可视反馈
系统 SHALL 对禁用和不可用节点提供一致的视觉反馈。

#### Scenario: 禁用节点显示差异
- **WHEN** 区域、存放柜或库位状态为禁用
- **THEN** 画布中使用弱化或禁用视觉样式
- **AND** 用户仍可识别其层级位置

#### Scenario: 加载失败提示
- **WHEN** 任一数据请求失败
- **THEN** 页面展示明确错误提示
- **AND** 保持当前页面结构可恢复或可重新选择库房

## MODIFIED Requirements
### Requirement: 库房浏览方式
系统 SHALL 在现有表格列表之外提供图形化浏览入口，而不是仅靠表格页层层切换查看空间结构。

#### Scenario: 从库房模块进入图形视图
- **WHEN** 用户访问库房可视化入口
- **THEN** 系统提供 2D 图形视图页面
- **AND** 现有库房、区域、存放柜、库位表格页面仍保持可用

### Requirement: 存放柜展示方式
系统 SHALL 在图形视图中展示存放柜的结构信息，而不仅展示列表字段。

#### Scenario: 存放柜显示网格能力
- **WHEN** 某存放柜存在 `rows` 和 `cols`
- **THEN** 系统用可感知的网格结构表达其容量布局
- **AND** 为后续 2.5D 视图和详情弹窗保留可扩展的显示模型

## REMOVED Requirements
### Requirement: 本轮必须提供拖拽式布局编辑
**Reason**: 第 18 个功能目标是先建立稳定的只读 2D 可视化基座，拖拽改位属于第 22 个布局编辑器范围。
**Migration**: 本轮通过推导式布局完成区域、柜、库位联动展示；后续在第 22 个功能中再引入坐标、拖拽与持久化编辑能力。
