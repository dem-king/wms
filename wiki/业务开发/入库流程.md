# 入库流程

## 涉及模块

`wms-business` → InboundOrder / InboundDetail

## 流程图

```
createOrder(创建) → submitOrder(提交) → StockSync(库存同步)
      ↓                    ↓                    ↓
   状态: 草稿(0)        状态: 已通过(3)       库存数量增加
```

## 关键业务规则

1. **创建入库单**
   - 校验库房存在且启用
   - 校验供应商存在（如指定）
   - 生成入库单号：`RK + yyyyMMdd + 4位流水号`（Redis INCR）
   - 状态设为草稿（DRAFT）
   - 计算金额：`数量 × 单价`

2. **提交入库单**
   - 仅草稿状态可提交
   - 状态流转：DRAFT(0) → PENDING(1) → APPROVED(3)
   - 发布 StockSyncEvent（STOCK_SYNC_IN）

3. **删除入库单**
   - 仅草稿状态可删除
   - 逻辑删除入库单 + 所有明细

## 数据库表

| 表 | 说明 |
|----|------|
| wms_inbound_order | 入库单主表 |
| wms_inbound_detail | 入库明细表 |

## 相关常量

| 常量 | 值 | 说明 |
|------|----|------|
| INBOUND_NO_PREFIX | "RK" | 入库单号前缀 |
| STOCK_SYNC_IN | "IN" | 入库同步方向 |
