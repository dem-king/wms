# 物品库存链路

## 涉及模块

`wms-item`

## 核心实体

| 实体 | 说明 | 关键字段 |
|------|------|---------|
| WmsItem | 物品档案 | itemCode, itemName, categoryId, subCategoryId, purchasePrice, stockLowerLimit, stockUpperLimit |
| WmsStock | 库存记录 | itemId, warehouseId, binId, quantity, lockedQuantity, lastInboundTime, lastOutboundTime |
| WmsCategory | 主类目 | 树形结构 |
| WmsSubCategory | 细分类目 | 归属主类目 |
| WmsTag | 标签 | 全局/自定义标签 |
| WmsElectronicLabel | 电子标签 | RFID 编码 |

## 关键业务规则

1. **编号生成**: 物品编号 `WP + yyyyMMdd + 4位随机数`（并发安全）
2. **库存安全**: 库存不足时抛 BizException，禁止静默修正
3. **库存同步**: 通过 StockSyncEvent 在业务单据提交后异步同步
4. **库存预警**: `quantity < stockLowerLimit → alert = true`

## 库存同步事件流

```
业务单据提交 (submitOrder)
  → StockSyncEvent 发布
    → StockSyncEventHandler 监听
      → 查找/创建 WmsStock 记录
      → 库存不足? → throw BizException
      → 更新 quantity + lastInboundTime/lastOutboundTime
```

## 相关常量

| 常量类 | 包含内容 |
|--------|---------|
| `ItemConstants` | 编码前缀、消耗品/可归还标志、默认库存量 |

| `TagConstants` | 标签范围类型 |
