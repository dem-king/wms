## 文档目标

- 审批流配置（多级 / 单级 / 自由）的设计
- 3 种策略：Free / Single / Multi
- 审批事件监听与库存事件发布的耦合
- 审批超时任务

## 当前已知要点

- 关键 Service: `wms-server/wms-approval/src/main/java/com/wms/approval/service/impl/ApprovalServiceImpl.java`
- 关键 Strategy: `wms-server/wms-approval/src/main/java/com/wms/approval/strategy/`
  - `ApprovalStrategy` — 策略接口
  - `FreeApprovalStrategy` — 自由审批（任何审批人可决）
  - `SingleApprovalStrategy` — 单级审批（一级审批完成即结束）
  - `MultiApprovalStrategy` — 多级顺序审批（按节点顺序）
  - `ApprovalStrategyFactory` — 策略工厂
- 关键枚举/常量: `ApprovalConstants`（流类型 ORDER/CONFIG、节点状态、审批结果）
- 关键 Listener: `wms-server/wms-approval/src/main/java/com/wms/approval/listener/`（监听业务单据事件）
- 关键 Task: `wms-server/wms-approval/src/main/java/com/wms/approval/task/`（超时扫描）

### 2. 3 种策略详解

- [ ] Free 策略：任何审批人可决（适用：低风险单据）
- [ ] Single 策略：一级审批（适用：常规单据）
- [ ] Multi 策略：多级顺序（适用：高风险/跨部门单据）
- [ ] 策略选择：在审批流配置中指定

### 3. 审批事件与库存事件

- [ ] 业务单据创建 → 发布 `ApprovalRequestEvent`（wms-common.event）
- [ ] wms-approval 监听 → 创建审批单
- [ ] 审批通过 → 发布 `ApprovalResultEvent`
- [ ] wms-business 监听 → 触发库存同步事件（参考 [AGENTS.md §4.2](../AGENTS.md)）
- [ ] 时序图：业务单据创建 → 审批 → 库存同步

### 4. 审批超时

- [ ] 超时任务：每 30 分钟扫描未决审批
- [ ] 超时处理：自动通过 / 自动拒绝 / 升级到上级
- [ ] 提醒：站内信 / 邮件 / 短信

- [ ] 审批人范围：基于角色的可见审批人
