# 库房管理链路

## 涉及模块

`wms-warehouse`

## 数据模型层次

```
WmsWarehouse (库房)
  └── WmsArea (区域)
        └── WmsCabinet (存放柜)
              └── WmsBin (库位)
```

## 编码规则

| 实体 | 编码前缀 | 编码格式 | 生成方式 |
|------|---------|---------|---------|
| 库房 | KF | KF + yyyyMMdd + 4位流水号 | SequenceGenerator |
| 区域 | QY | QY + yyyyMMdd + 4位流水号 | SequenceGenerator |
| 存放柜 | CG | CG + yyyyMMdd + 4位流水号 | SequenceGenerator |
| 库位 | - | 存放柜编码-行号-列号 | 结构拼接 |

## 关键业务规则

1. 库房有启用/禁用状态（`status` 字段，使用 `BizConstants.STATUS_ENABLED/DISABLED`）
2. 库房状态为禁用时，不能创建入库/出库单
3. 库位有占用状态（`isOccupied` 字段）
4. 删除全部为逻辑删除

## 相关常量

| 常量类 | 包含内容 |
|--------|---------|
| `WarehouseConstants` | 编码前缀、占用状态常量 |
| `BizConstants` | 启用/禁用状态 |
