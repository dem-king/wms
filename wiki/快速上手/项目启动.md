# 快速上手 — 项目启动

## 后端启动

```bash
cd wms-server
mvn spring-boot:run -pl wms-app -Dspring-boot.run.profiles=dev
```

或运行 `WmsApplication.java` 的 main 方法（IDE 中）。

默认端口：**8080**
Swagger 文档：http://localhost:8080/doc.html

## 前端启动

```bash
cd wms-web
npm run dev
```

默认端口：**3000**（Vite 开发服务器）
访问地址：http://localhost:3000

API 代理：`/api` → `http://localhost:8080`（配置在 vite.config.ts）

## 常见问题

### 1. 数据库连接失败

确保 MySQL 已启动，检查 `application-dev.yml` 中的连接信息。

### 2. Redis 连接失败

确保 Redis 已启动。开发环境 Redis 默认无密码。

### 3. 端口占用

| 端口 | 服务 |
|------|------|
| 8080 | 后端 Spring Boot |
| 3000 | 前端 Vite Dev Server |
| 3306 | MySQL |
| 6379 | Redis |
| 9000 | MinIO API |
| 9001 | MinIO Console |
