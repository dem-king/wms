# 快速上手 — 环境搭建

## 前置依赖

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 17+ | 推荐 Eclipse Temurin |
| Maven | 3.8+ | 用于后端构建 |
| MySQL | 8.0+ | 数据库 |
| Redis | 7.0+ | 缓存 |
| MinIO | latest | 对象存储 |
| Node.js | 18/20 LTS | 前端构建 |

## 安装步骤

### 1. 使用 Docker 启动中间件（推荐）

```bash
cd wms-server/docker
docker-compose up -d
```

将启动 MySQL (3306)、Redis (6379)、MinIO (9000/9001)。

### 2. 初始化数据库

使用 `database/` 目录下的 SQL 脚本创建表结构。

### 3. 配置环境变量

开发环境使用 `application-dev.yml` 中的默认配置即可。

```yaml
# application-dev.yml 关键配置
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/wms
    username: root
    password: wqy123456
  redis:
    host: localhost
    port: 6379
```

### 4. 构建后端

```bash
cd wms-server
mvn clean compile -DskipTests
```

### 5. 安装前端依赖

```bash
cd wms-web
npm install
```

## 验证环境

- 后端编译：`mvn compile` 成功
- 后端测试：`mvn test` 通过
- 前端编译：`npm run build` 成功
