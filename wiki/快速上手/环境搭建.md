## 前置依赖

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 17+ | 推荐 Eclipse Temurin |
| Maven | 3.8+ | 用于后端构建 |
| MySQL | 8.0+ | 数据库 |
| Redis | 7.0+ | 缓存 |
| MinIO | latest | 对象存储 |
| Node.js | 18/20 LTS | 前端构建 |

## 安装步骤

### 1. 使用 Docker 启动中间件（推荐）

```bash
cd wms-server/docker
docker-compose up -d
```

将启动 MySQL (3306)、Redis (6379)、MinIO (9000/9001)。

### 2. 初始化数据库

使用 `database/` 目录下的 SQL 脚本创建表结构。

### 3. 配置环境变量

开发环境使用 `application-dev.yml` 中的默认配置即可。**密码一律通过环境变量注入**，禁止硬编码。

```yaml
# application-dev.yml 关键配置（密码使用 ${ENV:default} 占位）
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/wms
    username: ${MYSQL_USERNAME:root}
    password: ${MYSQL_PASSWORD:}        # ⚠️ 必须设置环境变量 MYSQL_PASSWORD
  redis:
    host: ${REDIS_HOST:localhost}
    port: ${REDIS_PORT:6379}
    password: ${REDIS_PASSWORD:}       # ⚠️ 必须设置环境变量 REDIS_PASSWORD
```

#### Windows PowerShell 临时设置

```powershell
$env:MYSQL_PASSWORD = "your_password"
$env:REDIS_PASSWORD = "your_redis_password"
$env:JWT_SECRET = "your_jwt_secret_at_least_32_chars"
mvn spring-boot:run -pl wms-app -Dspring-boot.run.profiles=dev
```

#### Windows 系统级环境变量（推荐）

`系统属性` → `高级` → `环境变量` → `新建`：
- `MYSQL_PASSWORD`：MySQL 密码
- `REDIS_PASSWORD`：Redis 密码（如有）
- `JWT_SECRET`：JWT 签名密钥（≥ 32 字符）
- `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY`：对象存储密钥

#### Linux/macOS 临时设置

```bash
export MYSQL_PASSWORD="your_password"
export REDIS_PASSWORD="your_redis_password"
export JWT_SECRET="your_jwt_secret_at_least_32_chars"
mvn spring-boot:run -pl wms-app -Dspring-boot.run.profiles=dev
```

#### IntelliJ IDEA 配置

`Run/Debug Configurations` → `WmsApplication` → `Environment variables` → 添加上述 4 个变量。

### 4. 构建后端

```bash
cd wms-server
mvn clean compile -DskipTests
```

### 5. 安装前端依赖

```bash
cd wms-web
npm install
```

## 验证环境

- 后端编译：`mvn compile` 成功
- 后端测试：`mvn test` 通过
- 前端编译：`npm run build` 成功
- 启动后端前：`echo $MYSQL_PASSWORD` 应有输出（Linux/macOS）；`echo $env:MYSQL_PASSWORD` 应有输出（PowerShell）
