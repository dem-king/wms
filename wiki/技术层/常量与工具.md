## 文档目标

- 一表展示 21 个公共常量类的位置、用途、关键字段
- 2 个公共工具类（LogicDeleteHelper、SequenceGenerator）的接口规范
- 强制规则（[AGENTS.md §4.3.1](../AGENTS.md)）: 公共常量在 `wms-common.constant`，模块常量在 `module.domain.constant`
- 反例：`public static final` 散落在 ServiceImpl/Controller

| 工具类 | 路径 | 关键方法 | 用途 |
|--------|------|---------|------|
| `LogicDeleteHelper` | `com/wms/common/util/LogicDeleteHelper.java` | `markDeleted(mapper, entityClass, id)` / `markDeletedEntities(mapper, entityClass, entities)` | 逻辑删除统一入口，避免 `@TableLogic` 字段被 MyBatis-Plus 跳过 |

## 强制规则（[AGENTS.md §4.3.1](../AGENTS.md)）

```java
// ✅ 正确：公共常量放 wms-common.constant
package com.wms.common.constant;
public final class DelFlagConstants {
    public static final int DELETED = 1;
}

// ✅ 正确：模块常量放模块的 domain.constant
package com.wms.item.domain.constant;
public final class ItemConstants {
    public static final String ITEM_NO_PREFIX = "WP";
}

// ❌ 错误：业务常量散落在 ServiceImpl/Controller
public class InboundServiceImpl {
    public static final String ORDER_NO_PREFIX = "RK";  // 必须提到 OrderConstants
}
```
