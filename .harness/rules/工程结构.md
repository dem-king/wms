# 工程结构规则

## 一、模块依赖约束

### 1.1 依赖层次（自上而下，不可逆向）

```
wms-app (启动入口)
  ├── wms-common     → 基础层：公共注解、配置、异常、枚举、常量、工具、事件
  ├── wms-system     → 依赖 wms-common
  ├── wms-auth       → 依赖 wms-common, wms-system
  ├── wms-warehouse  → 依赖 wms-common
  ├── wms-item       → 依赖 wms-common, wms-warehouse
  ├── wms-business   → 依赖 wms-common, wms-item, wms-warehouse, wms-system
  ├── wms-approval   → 依赖 wms-common, wms-business, wms-system
  ├── wms-report     → 依赖 wms-common, wms-business, wms-item, wms-warehouse, wms-system
  └── wms-monitor    → 依赖 wms-common, wms-item, wms-warehouse, wms-business, wms-system
```

`wms-app` 只作为启动聚合模块依赖所有业务模块；其他模块不得反向依赖 `wms-app`。

### 1.2 包结构规范

每个业务模块必须遵循以下包结构（基础分层）：

```
module-name/
├── controller/       # Controller 层（仅参数校验+调用Service）
│   └── {sub}/        # 大型模块的二级分类（如 wms-business.controller.pda）
├── service/
│   └── impl/         # Service 实现
│   └── support/      # 跨 Service 复用工具（如 BinWarehouseValidator）
│   └── {sub}/        # 大型模块的二级分类（如 wms-business.service.pda）
├── mapper/           # MyBatis Mapper 接口
├── converter/        # Entity ↔ Vo 转换器
├── domain/
│   ├── entity/       # 数据库实体
│   ├── dto/          # 入参 DTO
│   ├── vo/           # 出参 VO
│   └── constant/     # 模块级常量（CONST-03 强制）
├── event/            # 业务事件
├── listener/         # 事件监听器
├── strategy/         # 策略模式（如审批策略）
├── task/             # 定时任务
├── manager/          # 业务管理器（跨 Service 编排）
└── util/             # 模块级工具
```

特殊模块补充包：

| 模块 | 补充包 | 用途 |
|------|--------|------|
| wms-common | `annotation/`、`config/`、`constant/`、`context/`、`datascope/`、`enums/`、`event/`、`exception/`、`storage/`、`util/` | 公共基础设施 |
| wms-auth | `config/`、`enums/`、`listener/`、`security/` | Spring Security 配置、认证枚举、事件监听、JWT 过滤器 |
| wms-system | `aspect/`、`manager/` | 数据权限/操作日志切面、配置管理器 |
| wms-warehouse | （基础包） | — |
| wms-item | `task/`、`util/` | 闲置检测任务、QR 码工具 |
| wms-business | `event/`、`listener/`、`controller/pda/`、`service/pda/impl/`、`domain/dto/pda/`、`domain/vo/pda/` | 库存事件、审批结果监听、PDA 专用接口 |
| wms-approval | `listener/`、`strategy/`、`task/` | 审批事件监听、策略模式（Free/Single/Multi）、超时任务 |
| wms-monitor | `task/` | 库存预警扫描、逾期归还扫描 |
| wms-report | `config/`、`exporter/`、`task/` | 高德地图配置、Excel/PDF 导出器、日聚合任务 |

### 1.3 公共组件位置

- 公共注解：`wms-common/src/main/java/com/wms/common/annotation/`
- 公共枚举：`wms-common/src/main/java/com/wms/common/enums/`
- 公共常量：`wms-common/src/main/java/com/wms/common/constant/`（CONST-03 强制）
- 公共异常：`wms-common/src/main/java/com/wms/common/exception/`
- 公共工具：`wms-common/src/main/java/com/wms/common/util/`
- 公共配置：`wms-common/src/main/java/com/wms/common/config/`
- 公共事件：`wms-common/src/main/java/com/wms/common/event/`
- 公共数据权限：`wms-common/src/main/java/com/wms/common/datascope/`、`context/`
- 公共存储策略：`wms-common/src/main/java/com/wms/common/storage/`

模块级常量（CONST-03 强制）：`{module}/src/main/java/com/wms/{module}/domain/constant/`

## 二、分层架构硬性约束

### 2.1 Controller 层
- **可以做的**：参数校验（@Valid）、调用 Service、包装 R.ok() 返回
- **不可以做的**：
  - Entity → Vo 转换（必须在 Service/Converter 中完成）
  - SecurityUtil 调用（移到 Service）
  - 任何业务判断或数据组装

### 2.2 Service 层
- 公共方法必须返回 VO，禁止返回 Entity
- 必须使用 @Transactional(rollbackFor = Exception.class) 标注写操作
- 禁止使用 private toVo 方法，必须用独立 @Component Converter 类
- 查询必须用批量查询+Map 避免 N+1

### 2.3 Mapper 层
- 禁止使用物理删除：mapper.delete(wrapper)、deleteById(id)、deleteBatchIds(ids)
- 禁止手动拼接 .eq(Xxx::getDelFlag, 0)

### 2.4 前端
- API 定义统一在 src/api/ 目录按模块组织
- 状态管理使用 Pinia，不可写 composable 绕过
- 参数命名必须与后端 DTO 字段名一致（小驼峰）

## 三、文件命名约束

| 类型 | 后缀/命名 | 示例 |
|------|----------|------|
| Entity | Xxx（无后缀） | WmsInboundOrder |
| DTO | XxxDto | InboundOrderDto |
| VO | XxxVo（小写o） | InboundOrderVo |
| Converter | XxxConverter | InboundOrderConverter |
| Mapper | XxxMapper | WmsInboundOrderMapper |
| Service | XxxService | InboundService |
| ServiceImpl | XxxServiceImpl | InboundServiceImpl |
| Controller | XxxController | InboundController |
| 常量类 | XxxConstants | DelFlagConstants |
| 枚举类 | XxxEnum | OrderStatusEnum |
| 配置类 | XxxConfig | RedisConfig |
| 测试类 | XxxTest | BizExceptionTest |
