# 质量门禁规则

> 所有门禁条件必须可程序化验证。自然语言描述的质量要求对 Agent 无效。

---

## 一、CI 门禁（GitHub Actions 自动执行）

### 1.1 后端门禁

| 门禁项 | 判定条件 | 失败处理 |
|--------|---------|---------|
| 编译通过 | `mvn compile` exit code = 0 | 回退到编码阶段 |
| 测试通过 | `mvn test` exit code = 0 | 回退到测试编写阶段 |
| 测试覆盖率 > 0 | `total_tests > 0` | 回退到测试编写阶段 |
| 无编译警告 | `mvn compile` 无 WARNING（可选） | 记录但不阻断 |

### 1.2 前端门禁

| 门禁项 | 判定条件 | 失败处理 |
|--------|---------|---------|
| 类型检查 | `vue-tsc --noEmit` exit code = 0 | 回退到编码阶段 |
| 构建成功 | `npm run build` exit code = 0 | 回退到编码阶段 |
| 测试通过 | `vitest run` exit code = 0 | 回退到测试编写阶段 |

### 1.3 全局门禁公式

```
PASS = (backend.compile == SUCCESS)
    && (backend.test.exit_code == 0 && backend.test.total > 0 && backend.test.passed == backend.test.total)
    && (frontend.typecheck == SUCCESS)
    && (frontend.build == SUCCESS)
    && (frontend.test.exit_code == 0)
```

## 二、代码审查门禁（Agent-to-Agent Review）

### 2.1 自动化规则扫描

| 规则扫描项 | 检查工具 | 必须通过 |
|-----------|---------|---------|
| 物理删除检查 | grep `mapper.delete(wrapper)` / `deleteById` / `deleteBatchIds` | ✅ |
| del_flag 冗余条件 | grep `.eq(.getDelFlag,` | ✅ |
| 查询最大编号+1 | grep `likeRight.*orderByDesc.*LIMIT 1` | ✅ |
| @PreAuthorize 缺失 | 扫描 @XxxMapping 方法 | ✅ |
| @DataScope 缺失 | 扫描 page/list/getById/search 方法 | ✅ |
| @OperLog 缺失 | 扫描 create/save/update/delete 方法 | ✅ |
| 魔法数字 | 扫描直接数值赋值 | ⚠️ 警告 |
| ServiceImpl 私有常量 | 扫描 `private static final` | ⚠️ 警告 |

### 2.2 评审循环上限

| 评审类型 | 最大轮次 | 超出处理 |
|---------|---------|---------|
| 编码评审 | 2 轮 | 升级到人工决策 |
| 复杂度 > 5 文件 | 3 轮 | 升级到人工决策 |

## 三、人工确认点（Human-in-the-Loop）

| 确认点 | 触发时机 | 确认内容 |
|--------|---------|---------|
| HITL-1 | 需求分析完成 | spec.md 摘要确认，用户故事与验收标准 |
| HITL-2 | 编码评审通过 | 代码变更摘要确认 |
| HITL-3 | CI 验证通过 | 部署环境参数确认 |

---

## 四、回退路径（Rollback Routes）

```
CI 失败 →
  ├── 编译错误 → 回退到阶段 2（编码实现）
  ├── 测试 0/0 → 回退到阶段 4（测试编写）
  ├── 测试失败 → 回退到阶段 4（测试编写）
  └── 需求不符 → 回退到阶段 1（需求分析）

编码评审失败 →
  └── REVISION REQUIRED → 回退到阶段 2（编码实现）
```
