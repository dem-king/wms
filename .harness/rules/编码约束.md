# 编码约束规则

> 每条规则都对应一个可程序化验证的条件。不可被机器验证的约束对 Agent 无效。

---

## 一、安全检查规则（违反即阻断）

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| SEC-01 | 所有 Controller 方法必须有 `@PreAuthorize` | 扫描 `@XxxMapping` 方法 → 检查注解 |
| SEC-02 | 所有查询方法必须有 `@DataScope` | 方法名包含 `page/list/getById/search` → 检查 `@DataScope` |
| SEC-03 | 所有增删改方法必须有 `@OperLog` | 方法名包含 `create/save/update/delete/remove/submit/approve/batchCreate` → 检查 `@OperLog` |
| SEC-04 | 配置文件中禁止硬编码密码/密钥 | 检查 `password/key/secret` 字段值不等于占位符模式 `$ {...}` |

---

## 二、数据操作规则（违反即阻断）

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| DB-01 | 禁止物理删除 | 代码中不能有 `mapper.delete(wrapper)` / `mapper.deleteById` / `mapper.deleteBatchIds` |
| DB-02 | 禁止手动拼接 del_flag=0 | 代码中不能有 `.eq(Xxx::getDelFlag, 0)` 或 `.eq("del_flag", 0)` |
| DB-03 | 逻辑删除必须用 DelFlagConstants.DELETED | 逻辑删除代码必须使用 `DelFlagConstants.DELETED` 常量而非直接写 `1` |
| DB-04 | 主键必须用雪花 ID | Entity 主键必须有 `@TableId(type = IdType.ASSIGN_ID)` |
| DB-05 | SQL 建表不含 AUTO_INCREMENT | DDL 文件中的主键定义不能含 `AUTO_INCREMENT` |
| DB-06 | 批量插入必须用 saveBatch | 循环内不能有 `mapper.insert()`，必须用 `Db.saveBatch(list)` |

---

## 三、编号生成规则（违反即阻断）

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| SEQ-01 | 禁止使用"查询最大编号+1" | 代码中不能同时出现 `likeRight + orderByDesc + .last("LIMIT 1")` |
| SEQ-02 | 必须使用 SequenceGenerator | 编号生成必须调用 `sequenceGenerator.next(prefix)` |

---

## 四、硬编码与常量规则

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| CONST-01 | 禁止魔法数字（状态值/类型值/标志位） | 扫描 `= 0` / `= 1` 等赋值，排除定义行和循环变量 |
| CONST-02 | ServiceImpl 中禁止私有常量 | ServiceImpl 中不能有 `private static final` 定义 |
| CONST-03 | BizException 异常信息必须精确 | 同类场景不能合并异常信息（如 "库房不存在或已禁用" 应拆为两条） |

---

## 五、分层约束规则

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| ARCH-01 | Controller ≠ 业务逻辑 | Controller 方法体不能超过 5 行（不含 @ 注解行） |
| ARCH-02 | 返回 VO 非 Entity | Service 和 Controller 公共方法返回类型必须是 XxxVo |
| ARCH-03 | 使用独立 Converter | ServiceImpl 中不能有 `private XxxVo toXxxVo(` 方法 |
| ARCH-04 | Controller 参数必须校验 | 有 @PathVariable/@RequestParam 时必须有对应的 @Min/@NotBlank 等校验 |

---

## 六、性能规则

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| PERF-01 | 禁止 N+1 查询 | 列表查询 for 循环内不能有 `mapper.selectById`（需人工审查） |
| PERF-02 | 禁止全表查询后内存过滤 | 先 `selectList()` 再 `.stream().filter()` 为违规模式 |
| PERF-03 | 编号生成保证并发安全 | 见 SEQ-01 / SEQ-02 |

---

## 七、库存安全规则（业务特有）

| 规则ID | 规则 |
|--------|------|
| INV-01 | 库存不足必须抛 BizException，禁止静默设为 0 |
| INV-02 | 库存同步事件必须在 submitOrder/审批通过后发布，禁止在 createOrder 时发布 |

---

## 八、前后端命名一致性规则

| 规则ID | 规则 |
|--------|------|
| NAME-01 | 后端 DTO/VO 字段使用小驼峰，前端 API 参数也必须使用小驼峰 |
| NAME-02 | 禁止后端用 `warehouseId` 而前端用 `warehouse_id` 等不一致情况 |

---

## 九、命名后缀约束规则

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| NAME-03 | VO 类名必须以 `Vo` 结尾 | 扫描 `domain/vo/` 目录，类名必须匹配 `*Vo.java` |
| NAME-04 | DTO 类名必须以 `Dto` 结尾 | 扫描 `domain/dto/` 目录，类名必须匹配 `*Dto.java` |
| NAME-05 | Converter 类名必须以 `Converter` 结尾 | 扫描 `converter/` 目录，类名必须匹配 `*Converter.java` |

---

## 十、JavaDoc 注释规则

| 规则ID | 规则 | 可程序化验证 |
|--------|------|-------------|
| JAVADOC-01 | Entity 每个 `private` 字段必须有 `@Schema` 注解或 JavaDoc `/** */` | 扫描 Entity 文件，每个字段上方必须有 `@Schema` 或 `/**` |
| JAVADOC-02 | Service/Controller 类必须有类级 JavaDoc `/** */` | 类声明 `public class` 上方 5 行内必须有 `/**` |
| JAVADOC-03 | Mapper 接口方法必须有 JavaDoc `/** */` | Mapper 方法上方必须有 `/** */`（排除 MyBatis-Plus 继承方法）
