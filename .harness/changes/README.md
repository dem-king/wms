# 变更管理目录

本目录用于存放每个需求的完整变更记录。

## 目录命名规范

```
{变更类型}-{需求简称}-{YYYYMMDD}/
```

变更类型：feat（新功能）、fix（修复）、refactor（重构）、docs（文档）、test（测试）

示例：
```
feat-物品二维码导出-20260518/
fix-入库单号并发-20260518/
```

## 单个变更目录结构

```
{变更目录}/
├── summary.md                    # 全流程追溯摘要
├── spec.md                       # 需求分析文档
├── tasks.md                      # 任务拆分清单
├── coding_report.md              # 编码报告
├── review/
│   ├── code_review_v1.md         # 编码评审（版本递增）
│   └── code_review_v2.md
├── test_report.md                # 测试报告
├── ci_result.md                  # CI 运行结果
└── deployment.md                 # 部署验证报告
```
